# sistema-atendimento-conta-cidadao

Objetivo: Permitir o gerenciamento de atendimentos a cidadaos para recuperacao de conta de governo.

Principais funcionalidades:
- Validação da identidade do cidadão para habilitar a recuperação da conta;
- Alterar dados da conta do cidadão;
- Consulta dos atendimentos realizados;
- Emissão de relatórios de atendimentos;
- Abertura de solicitação ao canal de suporte para cidadão cuja identidade não foi verificada ou menor de idade.
